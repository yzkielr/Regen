# Folder foto tutorial

- /PenCartridge: simpan 01.png sampai 06.png di public/PenCartridge/.
- /Basic: simpan 01.png sampai 04.png di public/basic/.

Ukuran dan versi cache gambar dibaca otomatis. Foto ditampilkan berurutan ke bawah, tanpa dipotong. Format JPG, JPEG, dan WebP juga didukung dengan nomor yang sama. Gunakan satu file per nomor.

Setelah mengganti foto, perubahan harus masuk commit, push, dan deployment terbaru agar website aktif ikut berubah.
